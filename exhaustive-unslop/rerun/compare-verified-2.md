# Competitor comparison, second pass, verified 2026-11-17

Every cell was checked against the vendor's own docs, help pages or README. Duet's help articles and Deskreen's FAQ answers only load with JavaScript, so they were read in a real browser or from the site's own JS bundle (the FAQ answer text). "Not documented" means the vendor's pages don't say either way. Don't write it on the site as "doesn't support X".

Cells marked **(?)** are ones I'm not fully sure of; see the notes below the table.

ScreenExtend, for reference: an offline hosted Wi-Fi network on Windows (no router needed), GPU encoding (NVENC / Quick Sync / VideoToolbox), per-device scale / orientation / refresh rate / quality, several extra screens each as its own virtual display, touch input, encrypted stream, and QR pairing with a 6-digit code.

## Notes on the (?) cells

- **Sidecar row 1:** the USB part is certain. For wireless, the support article lists only Wi-Fi + Bluetooth + Handoff within 10 m, while the macOS User Guide adds "on the same Wi-Fi network". So "No router needed" is only safe to claim for USB.
- **Sidecar row 3:** Apple only says "some Display settings". In practice the iPad shows up in Displays settings with scaling options, but Apple doesn't list them, so leave it as "not documented" or "partial".
- **Sidecar row 4:** Apple never states a limit. It is widely known to be one iPad per Mac, but no Apple page says so.
- **Deskreen row 4:** "Connect as many devices as you want" refers to sharing one screen or window to many viewers. Several *independent* extended screens would each need a virtual display (dummy plug or third-party driver). Community is capped at 1 device.
- **Spacedesk row 2:** the setting sits in the viewer's settings menu, but the Windows driver release notes confirm host-side hardware encoding (the Intel graphics fix). NVENC / AMD aren't named.
- **Duet row 6:** both encryption statements are about remote / over-internet connections. Nothing on local USB or Wi-Fi.
- **Duet row 4:** an older App Store developer reply said one device at a time; the current plans page lists multiple displays under Pro. Use the plans page.
- **Spacedesk QR:** neither the manual nor the homepage mentions QR. The Spacedesk HTML5 viewer may change this, but nothing is documented.
